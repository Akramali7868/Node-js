What are Network Interfaces

Network Interfaces
Devices which is used to access internet
It is minimum 4 ways in mobile and Computer
Computer
1. Wifi or we use wifi card
2. internet is way to use a lan cable and connect to our computer internet port (Speed depends on Cable Quality)
3. Bluetooth use Bluetooth as data transfer between mobile and pc vie enabling Bluetooth  tethering 
4. USB is used between phone and computer 

Speed Comparison
Internet Port > USB Cable > Wifi > Bluetooth

In Phone
1. Wifi
2. Bluetooth
3. USB
4. Cellular Data (SIM Card)


Network Interface ka matlab hai wo medium (mostly hardware) jiske through ek device internet ya kisi network se connect hota hai.
Har interface ko ek unique IP address assign hota hai, jisse device network pe identify hota hai.

💻 PC (Computer) me Internet Access ke Interfaces
Wi-Fi (Router ke through)
Wireless connection, most common.
Speed aur reliability router pe depend karti hai.
Ethernet Cable (LAN)
Direct wired connection router → PC.
Har PC me Ethernet port nahi hota.
Advantage: Stable, fast, no network loss.
Bluetooth Tethering
Mobile → PC internet sharing via Bluetooth.
Requirement: Mobile me Bluetooth Tethering ON ho.
Ye ek PAN (Personal Area Network) banata hai.
USB Tethering
Mobile → PC internet sharing via USB cable.
Requirement: Mobile me USB Tethering ON ho.
Ye bhi ek PAN create karta hai.
Stable compared to Bluetooth.
👉 Note: Bluetooth aur USB tethering dono me hi PC ko naya IP address assign hota hai (alag network interface ki tarah).

Mobile (Phone) me Internet Access ke Interfaces
Wi-Fi (Router ya hotspot ke through)
Bluetooth (tethering / PAN)
USB (PC ke through ya tethering)
Cellular Data (SIM ka data) – 4G/5G.

💡 Key Point
Har interface ek alag network path provide karta hai.
Agar ek device me multiple interfaces available hain (e.g., Wi-Fi + Ethernet), to OS decide karta hai kaunsa use karna hai (priority settings se).

⚡ Example:
Agar PC Wi-Fi se connected hai aur simultaneously USB tethering bhi laga hai, dono alag-alag IP assign karenge. Lekin ek time pe ek hi route active hoga (jisko OS prefer karega).
