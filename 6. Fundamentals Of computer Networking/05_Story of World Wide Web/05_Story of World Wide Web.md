Story of World Wide Web
→ 1989 – Tim Berners-Lee working at CERN (Switzerland) noticed that documents contained highlighted text (hypertext) that said “read more on page 30”, but readers had to manually go there.
 He wanted users to click and open directly, so he created HTML (HyperText Markup Language) and a software to read it (the first web browser) — World Wide Web (WWW).
→  To make these pages work over the internet, he also created a communication protocol called HTTP, which defines how a browser requests a page and how a server responds.
→ 1991 – The first website went live through the WWW using HTML
