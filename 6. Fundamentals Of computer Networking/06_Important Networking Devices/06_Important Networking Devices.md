Types of Network

1. LAN => Local Area network => Ek home ke andar multiple device connected hai ya wife se
2. MAN => MEtroPolitan Area Network => EK city ke andar all device connected hai ye LAN se bada hota hai
3. WAN => Wide Area Network ye sabse bada hota hai Like internet ye alag alg counties ko connect kiya jata hai

4. CAN => campus Area Network
5. PAN => Personal Area Network
6. BAN => Body Area Network
7. SAN => Storage Area Network


1. PAN (Personal Area Network)
   => Small personal network around one person.

Example:
-> Bluetooth
-> Smartwatch connection

2. LAN (Local Area Network)
   => Network within a small area.

Example:
-> Home WiFi
-> School lab

3. WLAN (Wireless LAN)
   => Wireless version of LAN.

Example:
-> WiFi network

4. CAN (Campus Area Network)
   => Network connecting multiple buildings in a campus.

Example:
-> University network

5. MAN (Metropolitan Area Network)
   => Network covering a city.

Example:
6. WAN (Wide Area Network)
   => Network covering large geographical areas.

Example:
-> Internet

7. SAN (Storage Area Network)
   => High-speed network for storage devices.

Example:
-> Data centers

8. VPN (Virtual Private Network)
   => Private secure network over the internet.

Example:
-> Company remote access VPN

9. Intranet
   => Private internal organizational network.

Example:
-> Company employee portal

10. Extranet
    => Private network shared with external users.

Example:
-> Supplier access system
11. BAN (Body Area Network)
    => A network of devices connected around a human body.

Example:
-> Smartwatch
-> Fitness band
-> Heart-rate monitor
