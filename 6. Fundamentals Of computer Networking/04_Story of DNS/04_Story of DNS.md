Story of DNS
Before DNS – hosts.txt (1970s–1983)
        Early ARPANET used a file called hosts.txt to map names to IPs.
        Elizabeth Feinler and her team at SRI managed this file and helped define top-level domains like .com, .edu, .gov.
        ❌ Problem: File grew too large, hard to maintain as the network expanded.
    
    Invention of DNS – 1983
        Paul Mockapetris created DNS to replace hosts.txt.
        DNS was distributed, hierarchical, and scalable.
        It allowed automatic name-to-IP resolution using servers.

    Integration into Applications
        Tools like Telnet, FTP, and email started using domain names instead of IPs.
        Before: telnet 193.34.23.2
        After:  telnet example.com

    DNS Today
        Supports millions of domains, security (DNSSEC), and global scalability.
        Critical for websites, emails, apps, IoT, and cloud services.
Story of dna 'domain name system'
[1983] : Paul Mockapetris designed the Domain Name System.
[1983] : The original DNS design was described in RFC 882 and RFC 883
[1980-1990]:the Internet expanded rapidly.
DNS became an essential part of Internet communication because users could use names instead of remembering numerical IP addresses.
Instead of:
142.250.xxx.xxx


DNS Kya Hota Hai?
Socho tumhe kisi friend ke ghar jaana hai, lekin tumhe sirf uska naam pata hai, address nahi. Toh tum kya karoge?
👉 Tum kisi directory (phonebook) ya Google Maps se uska address search karoge na?
Bas, DNS bhi internet ki address book hai.

💻 Jab tum "google.com" likhte ho browser mein...
Tumhara computer actually Google ka IP address dhoondta hai (jaise 142.250.193.78), kyunki internet sirf numbers/IP samajhta hai — names nahi.
Problem Ye Thi (Pehle Zamane Mein 😅):
Sab computers ke paas ek hosts.txt file hoti thi.
Is file mein sab websites ke naam aur unke IP likhe jaate the.
Jaise:
142.250.193.78    google.com
123.45.67.89      facebook.com
Jab website badhne lagi, ye file bahut badi aur mushkil ho gayi manage karna.
